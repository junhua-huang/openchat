# 交付验证记录

## 2.1.1 输入栏、键盘与滚动

恢复独立加号和胶囊输入栏，移除服务名和独立工具按钮；关闭聊天顶部与底部的系统滚动边缘遮罩。点击聊天正文或开始拖动立即收起键盘。工具与附件入口仍在加号及顶部菜单。

欢迎页变为第一段对话、切换历史时重建滚动位置，流式文字、附件、工具和键盘变化合并为布局后的滚动请求。新增原生交互测试验证点击／拖动收键盘，以及从空对话连续发送三次、流式回复结束后末段实际位于可见区域。合成测试不调用真实模型。

公开网页读取取消重复授权，验证连续两次读取均不弹确认、不携带账户凭据，非法协议及含凭据 URL 在网络请求前拒绝；MCP 等待、拒绝与停止测试继续保留。当前 128 项单元测试、8 项原生交互测试，以对应提交的 CI 结果为准。

## 2.1 后台、工具时间线与 MCP 发现

当前 128 项单元测试、6 项原生交互测试。移除两项已删除的云端文件测试，补充后台失联等待与恢复、系统到期取消流、前台故障不自动重试、暂停时停止、已完成文件不重放、仅撤回当前未完成文字，以及 Unicode 时间线和旧版回复兼容。新增 MCP 目录请求脱敏、输入编码、分页去重、迟到结果隔离、协议及授权兼容检查。

原生 XCUITest 增加 Home 后返回继续显示合成回复、回答底部打开工具记录、深色模式开关状态和推荐地址预填、离线目录搜索。后台自动化使用本地合成延迟，不冒充真实移动网络挂起的模型测试；实际手机和套餐服务仍需新版验收。iOS 短时后台保护不承诺无限运行或进程终止后自动续传。

Release、Debug 测试及截图以对应提交 CI 为准。`Scripts/check_mcp.py` 编译实际 Foundation Registry/MCP 客户端，只做公开目录搜索与推荐服务 initialize/tools/list，不发送模型密钥、MCP 凭据或 tools/call。该公网可用性探测与确定性的单元测试分开记录。

## 2.0.3 历史入口与工具流验证

新增 8 项工具流回归测试和 2 项原生 XCUITest 交互测试。覆盖稀疏终止事件、分段工具参数、完成参数去重、最终加密推理、未完成或冲突调用阻断、附件引用保留、实际生成 DOCX 并回传结果，以及空白/仅推理回复失败提示。不会因空回复自动重试有副作用的工具。

顶部工具栏独立参与布局，滚动区域裁切并限定命中范围；历史、模型、设置、编辑和工具确认统一到一个 sheet 路由。XCUITest 使用屏幕坐标实际点击历史按钮，检查滚动后打开、关闭后重开、键盘弹出时打开，以及关闭后发送消息。合成界面不访问真实账户或付费模型。

流式输出收集有大小限制，参数片段不反复序列化整个项目。Debug 测试与 iOS Release archive 以该提交 CI 结果为准；工具流缺陷由合成事件复现，未获取用户真机原始流，因此不据此断言其服务端一定采用相同事件形状。真实套餐模型触发、附件保存和 TestFlight 安装仍需设备复测。

## 2.0.2 可靠性与性能验证

新增 13 项回归测试，总计 106 项。覆盖中断回复追问、重复容器引用与生成图片、无效图片编码、中文/emoji 文件名真实导出、ZIP 重名冲突、后台文档处理、工作线程取消、流式定时保存与重复进度不写盘、多行工具事件以及 HTTP/流式任务提前释放、无会话 MCP 的断开重连。

流式事件只反序列化一次，工具进度从经过校验的 SSE 事件中派发；相同进度跳过通知和磁盘写入。回复生成期间约每 2 秒保存检查点，切后台、停止和结束仍立即保存。长回复降低增量刷新频率，Word/Excel/ZIP 生成、附件解码/保存和容器文档提取移至可取消的后台任务；UIKit PDF 排版保留在主执行器。

云端同时验证 Debug XCTest、iOS Release archive 与不带密钥的真实公开搜索。运行结果以本次提交 CI 为准；无量化的真机性能基准，不宣称固定帧率或耗时提升。原有聊天布局不变。

## XCTest

`Tests/CoreTests.swift` 包含八个测试方法，已随 0.2 版在云端通过，覆盖：

1. PKCE S256 官方测试向量。
2. 带 Unicode 与保留字符的 form 编码。
3. SSE 注释、多行 data、空事件与结尾事件。
4. 只有 `response.completed` 且 `status=completed` 才成功；拒绝 incomplete／failed，不把 `[DONE]` 当成功。
5. 使用真实合成签名验证 RS256 与 ES256；拒绝错误 audience、issuer、nonce、过期、未来 iat、多 audience 缺 azp、篡改签名和 `alg=none`。
6. 缺少套餐权限时不启用推理。
7. 流式输出中未闭合的代码块、Unicode 内容。
8. 长围栏内的短围栏与 CRLF 换行。

0.3 新增 `Tests/APIClientTests.swift` 的十个方法，覆盖 HTTPS 地址与凭据校验、模型 ID 解析、Header 注入、端点与 Bearer Header、Unicode 上下文与中断消息排除、模型目录、流式正常完成、断流及服务商错误。样本密钥为合成值，不会调用真实服务商。

0.3.1 新增 `ResponsesWireTests.swift` 的十二个测试，覆盖最小推理请求、SSE 缺少或错误 MIME、多行 JSON 错误、HTML、空响应、JSON 完成事件、完成输出去重、中断流、诊断脱敏和旧聊天记录兼容。

0.3.2 增加五个方法，覆盖原始字节管线、CR/LF/CRLF 空行、Unicode、分散的 UTF-8、多行 data、EOF、空 data 心跳、边界丢失复现及细分诊断。均使用合成流，不连接真实模型。

1.0 新增 15 项测试，覆盖 Markdown 语义、回复版本往返、编辑分支、旧存档迁移、损坏存档保护、停止与迟到数据隔离、跨对话生成、选中版本作为追问上下文，以及草稿／置顶／选择恢复。合成 transport 不访问模型服务。

全部 50 个方法由 `Build and test iOS` 执行。新增方法的执行结果需查看本次提交 CI；本地没有运行 Swift XCTest，不能把语法检查当成测试通过。
