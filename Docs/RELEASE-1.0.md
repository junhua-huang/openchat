# OpenChat 1.0 体验升级

## 这一版可以做什么

- 多行写消息，发送后继续输入下一条；外接键盘可用 Command + Return 发送。
- 新建对话在右上角；账户与分享在更多菜单；每段对话分别记住未发送草稿。
- 长按自己的消息，选择“编辑并重新发送”。修改会创建新对话分支，保留原来的完整对话。
- 最后一条回复不论成功、失败或被停止，都能重新生成。用左右箭头查看旧版；追问会使用选中的版本。发出后续问题后，前面回复的版本选择固定。
- 在 App 内切换对话时，正在生成的回复继续接收；可以在历史列表看进度。切回该对话后可停止，已收到的文字会保留。离开 App 后的持续后台推理没有保证。
- 标题、列表、任务项、引用、表格和代码分别排版；宽表格与代码横向滚动；消息可选择文字、复制、分享。
- 历史对话可置顶、搜索正文、重命名、删除；整段对话可分享为 Markdown 文本。

## 升级与记录

自动读取 0.3 系列的 JSON 数组存档，写入包含对话、草稿与当前选择的新存档。旧消息没有版本、模型、置顶字段时仍能恢复。读取失败时暂停写入，不以空列表覆盖损坏文件。

## 验收重点

1. 发一段长问题，在回复中途上滑阅读，再点击向下按钮。
2. 回复未结束时打开另一段对话，再切回来；两段内容应各自归属正确。
3. 停止后立即重发；旧请求的迟到内容不应污染新回复。
4. 对成功回复重新生成，切到旧版本，再继续追问。
5. 编辑较早的问题；原来的对话和后续消息应保留。
6. 给两段对话分别留草稿，重开 App 后检查草稿、置顶与当前选择。
7. 检查深色、浅色、大字体、键盘和表格／代码横向滚动。

## 本轮边界

仍以文字聊天为主，没有加入图片生成、文件上传、联网搜索、完整语音对话、数学公式排版或与 ChatGPT 网页端既有会话同步。本次不改变账户授权与 API 服务商计费方式。
