# iPhone 登录与聊天验收

本页记录要实际执行的验证，不代表这些步骤已经通过。请先完成云端 Xcode 编译与 XCTest，再安装 TestFlight 构建。所查官方文档没有明确承诺这个开源回环流程在 iOS 可用，真机结果是首要判断依据。

## 最小成功链路

1. 启动聊伴，点击 **Continue with ChatGPT**。
2. 应出现系统 Safari 页面，登录地址属于 OpenAI 的 `auth.openai.com`。正常完成账号验证与工作空间选择；按自己的意愿同意使用 ChatGPT 套餐。
3. 保持在 App 内的系统浏览器中完成操作。不要主动点“在 Safari 打开”跳到另一个 App，也不要在登录期间把聊伴长时间放在后台；当前实现没有申请长期后台运行。
4. 授权后，应回到 App。正常情况下，Safari 页面可能先短暂显示“授权回调已收到”；登录完成后账户页应显示“身份与套餐授权已验证”。若跳转到回环地址后页面打不开、界面停留或三分钟超时，先记录 iOS 版本与 App 当前显示的阶段，不要复制包含 code、state 或 token 的完整地址。
5. 模型菜单应出现当前账户可展示的模型。列表成功仅证明拿到了目录，还要发送一条消息，例如“请只回复：你好”。
6. 应看到文字逐步出现，最终加载指示消失。源码只有收到 `response.completed` 且状态为 `completed` 才认定成功；`[DONE]`、断流或 `response.incomplete` 不算成功。
7. 关闭并重新打开 App，检查连接和对话恢复；发送第二条消息验证上下文。

## 回调失败时怎么判断

| 最后阶段／现象 | 优先检查 |
| --- | --- |
| 准备安全登录就失败 | 设备能否访问 OpenAI OIDC 元数据，是否有可用网络 |
| 一直等待浏览器授权 | 登录是否完成，OpenAI 是否接受本机回环地址，系统浏览器能否请求本机监听 |
| 已收到设备本地回调，但连接未完成 | 代码交换、正式 client_id、身份签名或 claims 验证 |
| 已登录，尚未授权套餐 | 用户是否同意套餐使用、返回的 scope 是否包含所需权限 |
| 模型列表可见但发消息失败 | 所选模型的实际权限、账号／工作空间限制、套餐额度 |

本机监听只绑定 `127.0.0.1`，不对局域网公开。系统是否弹出本地网络权限、浏览器与监听是否能互通，需要在实际 iOS 版本验证。Info.plist 包含本地网络说明，但这不构成平台兼容性保证。

如果确认平台不允许当前流程，应向 OpenAI 申请支持的原生客户端回调方式或选择其支持的集成架构。不要复用 Codex 的客户端身份，也不要用 ChatGPT 网页 cookie／`backend-api` 替代官方登录。

## 基本行为

- 在授权页取消：不新建可推理的连接，不进入聊天调用。
- 只同意身份、未同意套餐：能保留有效登录，但发送模型请求被禁用。
- 失败或停止生成：显示明确状态，可以重新生成；未完成的 assistant 片段不进入后续完整对话上下文。
- 切换账户／工作空间：记录与模型列表随连接切换，不把旧账户的聊天传给新账户。
- 等待令牌接近到期后继续发消息：应续期；失效时提示重新连接。重新连接复用所选连接的正式 client_id。
- 新客户端已注册但代码交换失败：保留“待完成的连接”，下次从该记录重新连接，避免把 `dynamic_agent_client` 当正式 client_id 保存。
- 退出：清除本机令牌并尝试远程撤销；远程撤销无法确认时明确提示。原客户端注册仍保留，可以从已有连接重新登录。
- 删除本机记录：仅影响当前连接的聊天文件，不删除 ChatGPT 账户或其他连接。

## 发布前还需要做什么

拿到上述真实结果后再决定发布。此原型尚未完成 App Store 审核、平台接入确认、可访问性与完整设备回归；隐私披露、开源项目资格与可能的付费接入应根据最终产品填写和确认。当前 UI 和说明没有宣称它是 OpenAI 官方产品。
